Limbi / Languages / Langues : RO · EN · FR (sus, dreapta / top right / en haut à droite).

Lecție interactivă pentru studenții de Informatică aplicată (BEng).

- Partea 1, lecție: ce este un jalon, cum îl recunoști, unda analistului, schema celor 8 etape.
- Partea 2, simulare: titlu, descriere, termen și sumă în MDL, USD sau EUR. Apoi tabelul etapelor.
- Fazele proiectului (`faze.html`): cele 4 faze, livrabilele fiecăreia și o întrebare de reflecție. Notițele studentului rămân doar în browserul lui.
- Exemplul ECIF este al unei firme. Dolarii și termenele de acolo nu sunt banii studentului.
- Sus, dreapta: RO sau EN.

Un singur link ajunge pentru toată grupa. Fiecare student simulează în browserul lui.
