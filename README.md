# Jaloane de proiect

Studenții deschid **un singur site**. Nu instalează nimic și nu au nevoie de cont.

**Lecție și simulare:** https://herodot91.github.io/jaloane-proiect/

**Faze, livrabile și reflecție:** https://herodot91.github.io/jaloane-proiect/faze.html

Apasă Lecție, apoi Simulare. Limba: RO, EN sau FR, sus în dreapta. Răspunsurile rămân în browserul fiecărui student.

## Instrumente și limbaje

Site-ul pe care îl deschid studenții este o pagină web. Nu trebuie compilat.

| Instrument | Rol |
| --- | --- |
| HTML5 | pagina lecției (`index.html`) și pagina fazelor (`faze.html`) |
| CSS3 | aspectul paginii, pe calculator și pe telefon |
| JavaScript | lecția, testele, schema, unda, simularea și tabelul |
| GitHub Pages | site-ul public, fără server propriu |
| Browser | Chrome, Edge, Firefox sau Safari. Merge și pe telefon |

Limbi ale interfeței: română, engleză, franceză.

În folderul `src/` există și notițe în TypeScript (React, Vite, Tailwind CSS, Recharts). Studenții nu le deschid. Ele nu sunt necesare ca să învețe sau să simuleze.

## Ce învață

- Partea 1, lecție: ce este un jalon, cum îl recunoști, unda analistului, schema celor 8 etape.
- Partea 2, simulare: titlu, descriere, termen și sumă în MDL, USD sau EUR. Apoi tabelul etapelor.
- Fazele proiectului: cele 4 faze, livrabilele și o întrebare de reflecție.
- Exemplul ECIF este al unei firme. Dolarii și termenele de acolo nu sunt banii studentului.
